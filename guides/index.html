Setting it up the first time

Takes about a minute. Mark the water once with F9 and it sticks — the bar and the catch popup are already recognised.

On this page

  1. 1Install and first run
  2. 2Mark where you fish
  3. 3Start fishing

1

Install and first run

Get it running and get past the SmartScreen warning.

  1. 1

    Download Hitmania-Windows.zip and extract it somewhere you won't mind it staying — Documents\Hitmania is a good spot. Moving the folder later means setting the cast point again.

  2. 2

    Run Hitmania.exe. Windows will probably say "Windows protected your PC" because the app isn't code-signed. More info, then Run anyway.

  3. 3

    If your antivirus flags it, add the Hitmania folder to your exclusions. Some antivirus tools dislike anything that moves the mouse on its own.

  4. 4

    The app writes config.json, a templates folder and macro.log next to the exe. Everything it knows lives in that folder.

2

Mark where you fish

One point, one key. That's the whole setup.

  1. 1

    Open Roblox and get into Steal an Egg. Leave the window somewhere sensible — the macro pins it to a fixed size for you.

  2. 2

    Aim at the water where you want the bobber to land.

  3. 3

    In Hitmania open the Setup tab and click Set cast point, or just press F9. It's saved straight away.

  4. 4

    Equip your fishing rod. Hitmania casts with whatever you're holding — it doesn't open your backpack.

  5. 5

    Nothing else needs setting up. The click-fast bar and the catch popup are matched from templates that come with the exe. Setup → Advanced → Detection has the capture buttons for the day Roblox changes how they look.

3

Start fishing

Hands off from here.

  1. 1

    Press Start fishing at the top of the window, or just hit F6.

  2. 2

    Click the Roblox window so it has focus. The macro window folds into a small badge in the corner, on top of the game, with the catch count and a Stop button.

  3. 3

    Press F6 again, or click Stop on the badge, to finish. The full window comes back with the session summary.

  4. 4

    Add a Discord webhook in Setup if you want every catch posted automatically.

4

When it doesn't work

The three problems people actually hit.

  1. 1

    Bar not detected: open Setup → Advanced → Detection and tick Live detection test to watch the confidence numbers. If they sit well below the threshold, capture the bar again with your cursor off it.

  2. 2

    Clicks landing in the wrong place: re-run F9 while aimed at the water. That's the only position the macro remembers.

  3. 3

    The macro stopped itself saying the template matches the idle screen: your bar template matches something that's always on screen. Recapture it while the bar is actually visible, or raise the threshold.

  4. 4

    Nothing happens at all: check macro.log next to the exe. If Roblox is running as administrator and Hitmania isn't, Windows blocks the input — run both the same way.
