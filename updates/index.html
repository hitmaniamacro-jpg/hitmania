Changelog

What changed and when

Every release, in order. If something broke for you, check here first.

v2.3.123 October 2026Latest

Fits the game window again

Recommended size on start, plus Linux/Wine notes

  • When you press Start, Hitmania fits Roblox to the recommended size again: 1246×638, the size the bar and catch-popup templates were captured at, shrunk to fit smaller screens. Detection scales, so any other size still works — this is just the sharpest one. Turn it off in Setup → Advanced → Game window if you'd rather it left the window alone.

  • Linux: Hitmania is a Windows app and runs under Wine/Proton. Window fitting, focus and the always-on-top badge can only reach windows in the same Wine prefix, so run Roblox in the same bottle as Hitmania. On Wayland, no application can move another application's window, and exclusive fullscreen is never resized — use windowed or borderless.

  • The log now says when it is running under Wine, and says plainly when the game window can't be found instead of quietly skipping the fit.

v2.322 October 2026

One key, then hands off

The bar and the popup come with it

  • Setup is one step now. Aim at the water, press F9, press Start fishing. The click-fast bar and the catch popup are recognised from templates that ship inside the exe, so there is nothing to capture on a first run.

  • The rod is yours to equip. Hitmania casts with whatever you're holding instead of digging through your backpack every cast — faster, and one less thing to break. The old backpack mode is still in Setup → Advanced if a game needs it.

  • Press Start and the big window folds into a small badge in the corner, always on top of Roblox. It shows the catch count, how long you've been running, the last thing you caught and a Stop button. The full window comes back when you stop.

  • Shipped templates now scale to your window size. Before, the bar was only recognised at the exact size it was captured at (1246×638), so a smaller window meant a weaker match.

  • The macro window stays above Roblox now. There's a toggle in the header if you'd rather it didn't.

  • Hotkeys are down to two: F6 to start and stop, F9 to mark the water. The capture keys still exist for game updates, unbound until you need them.

v2.222 October 2026

A quieter window

Softer colours, fewer knobs

  • The macro window had a proper clean-up. Softer, warmer colours, headings that read like sentences instead of shouting, and every panel now uses the same corners and spacing.

  • There is one button that matters and it is at the top: Start fishing, with the run state right next to it. The hotkeys are a single line now instead of a grid of little boxes.

  • Setup is in the order you actually do it — game window, then calibration, then Discord, then hotkeys — and the bar at the bottom tells you what is still missing instead of just saying "running".

  • Added a Restore defaults button under Advanced, for when you want to start over.

  • New purple brush emblem, and the app is called Hitmania.

v2.122 October 2026

It grabs the rod for you

Backpack rod, two-second pause

  • The rod in Steal an Egg lives in your inventory, not the hotbar, so pressing a number key never equipped it. Hitmania now opens the backpack, clicks the rod and starts fishing — then does it again before every cast, because the game puts the rod back in the backpack after each catch. Press F10 over the rod in your open backpack once and that's it.

  • If your game opens the inventory with a different key, change it in Setup → Advanced → Cast. There's a hotbar mode too, for games where the rod really is on a hotbar slot.

  • After every catch the macro waits two seconds before casting again. Casting while the reward popup is still animating away just wastes the catch, so it waits for the screen to settle.

  • Fixed the Post-catch wait setting — it was on screen but never actually saved.

v2.01 October 2026

Hitmania 2.0

Rebuilt from scratch

  • New black and purple interface, matching the site. The old one was grey and looked like a tool from 2009.

  • The detector was rewritten around OpenCV template matching. It now finds the click-fast bar by shape instead of brightness, which means it holds up much better in different lighting and with different skins.

  • Roblox gets pinned to a fixed window size, and every point you calibrated re-aligns itself when the window moves.

  • Discord webhook support — post every catch with a screenshot, plus hourly and on-stop session summaries.

  • Added a detection threshold slider and a live detection test in Setup, so you can see exactly what the macro sees.

  • Hotkeys are all rebindable now, and window bounds are remembered between sessions.

v1.212 August 2026

Faster reel loop

Less dead time between catches

  • Reeling now stops as soon as the bar disappears and the reward popup is confirmed, instead of waiting out a fixed timeout.

  • Fixed a bug where a dropped frame could make the macro click the bar twice.

v1.02 July 2026

First public build

It's alive

  • First release: automatic casting, click-fast minigame handling, and the Fish and Setup tabs.
